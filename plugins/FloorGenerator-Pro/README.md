# FloorGenerator Pro (v2.10 Extended)

Полноценный процедурный генератор полов и плитки для **Autodesk 3ds Max**, включающий **нативный C++ плагин (`.dlm`)** под 3ds Max SDK и **универсальный MAXScript (`FloorGenerator_v2.ms`)**.

## Возможности
- **7 паттернов укладки:**
  1. **Standard** — классическая палубная укладка со случайной длиной, шириной и смещением рядов.
  2. **Herringbone** — английская ёлочка ($\pm 45^\circ$) с поддержкой параллельных плашек (`Parallel Boards`).
  3. **Chevron** — французская ёлочка с регулируемым углом (`1°–85°`).
  4. **Basket Weave** — плетёнка с настраиваемым количеством полос в блоке (`Sub Boards`).
  5. **Hexagon** — шестиугольная плитка (соты).
  6. **Triangle** — равносторонняя треугольная сетка с идеально прямыми сквозными швами ($0^\circ, \pm 60^\circ$).
  7. **Octagon** — октагональная плитка со вставками-кабошонами (`Insert Size`), автоматическим назначением `MatID 1` (основная плитка) и `MatID 2` (вставка).
- **Точная математика распределений (`Spread`):** кусочно-рациональное распределение и ограничение поворота без самопересечений.
- **3D-геометрия и фаски:** `Extrude`, `Bevel`, `Outline` с расчётом биссектрис углов, корректная триангуляция вогнутых вырезов (Ear-Clipping) и группы сглаживания.
- **UVW-развёртка:** локальные планарные координаты для каждой доски/плитки с `Random Flip U/V` и `Random Offset U/V`.
- **Совместимость с `.ini` пресетами** оригинального FloorGenerator v2.10.

## Быстрый старт

### Способ 1: MAXScript (без установки компилятора)
Перетащите файл `maxscript/FloorGenerator_v2.ms` в окно вьюпорта 3ds Max (или `Scripting -> Run Script...`).

### Способ 2: Сборка нативного C++ плагина (`.dlm`)
Требования:
- **Visual Studio 2022** (или *Build Tools 2022*) с компонентами C++ (`MSVC v143` + `Windows 10 SDK`)
- **Autodesk 3ds Max SDK** (например, *3ds Max 2027 SDK*)
- **CMake** (добавленный в `PATH`)

Запустите из корня репозитория:
```bat
build_dlm.bat
```
После сборки готовый файл появится в `dist\FloorGenerator_v2.dlm`. Скопируйте его в папку `plugins\` вашего 3ds Max (например, `C:\Program Files\Autodesk\3ds Max 2027\plugins\`) и перезапустите 3ds Max.
